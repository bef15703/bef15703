## Projects

### Zero Trust, Encrypted Messenger - [Repo](https://github.com/bef15703/encrypted-messenger) | [Live Demo](https://encrypted-messenger-client.vercel.app)
*React 19, TypeScript, Node.js, Socket.io, PostgreSQL, Web Crypto API, IndexedDB, Vite, Docker/CI*
- Implemented an untrusted-relay cryptographic messaging protocol using client-side ECDH key agreement and AES-256-GCM authenticated payload encryption.
- Prevented server-side side-channel data leaks by restricting the backend relay to authenticated ciphertext routing and transient database queueing.
- Optimized client-side cryptographic throughput and localized key isolation by pairing browser Web Crypto primitives with structured IndexedDB stores.
